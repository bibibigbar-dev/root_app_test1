🔗 루트펀드 딥링크 테스트

✅ 이 페이지는 로컬 개발 환경에서 딥링크를 테스트하기 위한 페이지입니다.
💡 사용 방법:
1. 모바일 기기와 개발 컴퓨터를 같은 Wi-Fi에 연결
2. 터미널에서: python3 -m http.server 8000
3. 모바일 브라우저에서: http://[컴퓨터IP]:8000/test-deeplink.html
4. 버튼을 클릭하여 앱이 열리는지 확인

🎯 출금 관련 (추천)

📱 출금 신청 화면 🔐 출금 로그인 화면
로그인이 안 되어 있으면 자동으로 출금 로그인 화면으로 이동합니다.

📲 커스텀 스킴 (rootfund://)

홈 - 메인 화면 로그인 화면 마이페이지 상품 목록 프로모션 고객센터 회사 소개 채권거래소
커스텀 스킴은 로컬 환경에서도 항상 작동합니다! ✅

🌐 웹 URL (https://rootenergy.co.kr)

출금 신청 (HTTPS) 출금 로그인 (HTTPS) 메인 (HTTPS) 마이페이지 (HTTPS)
⚠️ Universal Links는 서버 설정이 필요합니다.
로컬 개발 시에는 커스텀 스킴을 사용하세요.

🧪 JavaScript 테스트

JavaScript를 사용하여 프로그래밍 방식으로 딥링크를 테스트합니다.

📝 ADB 명령어 (Android)

# 기기 확인
adb devices

# 출금 신청 화면 열기
adb shell am start -W -a android.intent.action.VIEW -d "rootfund://withdrawal"

# 웹 URL로 열기
adb shell am start -W -a android.intent.action.VIEW -d "https://rootenergy.co.kr/withdrawal"

🍎 xcrun 명령어 (iOS)

# 시뮬레이터에서 출금 신청 화면 열기
xcrun simctl openurl booted "rootfund://withdrawal"

# 웹 URL로 열기
xcrun simctl openurl booted "https://rootenergy.co.kr/withdrawal"
